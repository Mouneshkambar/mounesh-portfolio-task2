# Mounesh Kambar — Task 2 Portfolio

This project implements the internship task "Advanced CSS3 & Responsive Architecture".

## Included

- Semantic HTML5
- CSS Grid
- Flexbox
- Mobile-first responsive media queries
- CSS custom properties (variables)
- Light/dark theme toggle
- Keyboard focus styles
- Skip-to-content link
- Accessible contact form validation
- Reduced-motion support
- Four pages: Home, About, Projects, Contact

## Run locally

Open `index.html` in a modern browser.

For best testing, use Chrome and run Lighthouse from DevTools.

## Lighthouse

Test each page separately, especially:

- Accessibility
- SEO
- Best Practices
- Performance
